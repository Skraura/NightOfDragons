# What's New — v7.7.0

## 💕 Mate & Harem — Full Polish

### Smart mate filtering
The Primary Mate dropdown now only shows **compatible dragons** by default:
- Same species as the dragon being edited
- Opposite gender
- No shared direct parents

If the currently saved mate is incompatible (different species), it's still shown with a `⚠` prefix so you can correct it.

### Inter-species warning
If a mate pair has mismatched species, both the form and the Clan Canvas now show a red `⚠ Inter-species pair` warning instead of silently accepting the mismatch.

### Harem — click-to-toggle cards
The harem selection is now a visual card grid instead of a `<select multiple>`:
- **Click a card** to add/remove from harem
- Cards dim and use dashed border if the dragon shares a direct parent (not recommended pairing)
- ✓ checkmark on selected cards
- ⚠ warning icon on shared-parent candidates
- Filtered to same species as current dragon

### Detail panel — harem as chips
In the dragon detail view, harem members are now shown as compact horizontal chips (gender glyph, name, species) instead of a vertical list.

### Canvas mate panel
- Shows pair count in the section title
- Each pair card shows harem count for each partner (`+N harem`)
- Flags inter-species pairs in red
